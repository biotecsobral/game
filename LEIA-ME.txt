PATENT DNA - CENTRAL DE OPERAÇÕES
================================

O arquivo dashboard.html substitui o painel antigo. Foi feito para projetores e TVs em 16:9.

COMO USAR
1. Abra dashboard.html em um navegador (Chrome/Edge). Não precisa de internet.
2. Clique em INICIAR para começar o cronômetro de 60 minutos.
3. Quando uma equipe INICIAR a fase 1, clique uma vez em seu cartão.
   Clique outra vez a cada mudança de fase. No quinto clique, a equipe
   aparece como "Patente depositada!".
4. Para voltar uma fase, segure Shift e clique na equipe (ou clique direito).
5. Use TELA CHEIA para projetar sem elementos do navegador.
6. Use +5 MIN e -5 MIN para ajustar o tempo, caso necessário.
7. ZERAR PAINEL redefine as equipes e o cronômetro, após confirmação.

IMPORTANTE SOBRE O MONITORAMENTO
- As etapas são atualizadas MANUALMENTE pela coordenação neste dashboard.
- O dashboard NÃO recebe automaticamente as respostas dos celulares dos alunos.
  Para monitoramento remoto realmente automático, seria necessário conectar
  o site dos alunos e o painel a um banco de dados compartilhado em tempo real.
- O estado das equipes e o cronômetro ficam salvos no navegador do computador
  em que o dashboard é usado. Não apague os dados do site no navegador durante
  a atividade nem use janela anônima se quiser conservar esse progresso.
- Se o navegador for fechado com o cronômetro em execução, o tempo segue
  contando de acordo com o relógio do computador quando a página for reaberta.

LOGO
- Se quiser mostrar a logo original, ponha logo.png na mesma pasta
  de dashboard.html. Sem o arquivo, aparece a marca PATENT DNA embutida.
